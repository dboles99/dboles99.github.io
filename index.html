Method

Small experiments rather than large claims.

  1. 01QuestionEach project begins with a question and a written design.
  2. 02BuildCoding agents implement the design under test suites and review gates.
  3. 03MeasureEach change faces tests or an evaluation before it stays.
  4. 04RecordWhat fails goes into the record with its numbers.

The work proceeds through small experiments rather than large claims, because a change small enough to measure is also small enough to undo. Each one faces tests or an evaluation; what works stays, and what fails goes into the record with its numbers, since a negative result on paper saves more time than a success nobody measured.

However, a tested system still needs an argument behind it, so each project begins with a question and a written design. Coding agents then implement that design under test suites and review gates, which keeps the judgment with the author and the labor with the machine.
